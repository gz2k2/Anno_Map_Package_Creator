# Changelog

## 1.2.5

### Changed
- Reordered the main workflow so Island Packages comes before Island Database.
- Renamed the General tab to Island Database.
- Newly imported islands are assigned directly to the selected package.
- Added direct file and folder island import to the selected Island Package.
- Package region and package-specific GUID range are applied automatically when configured.
- Moved Add Islands controls to Island Packages.
- Island Database is now the central overview without import controls.
